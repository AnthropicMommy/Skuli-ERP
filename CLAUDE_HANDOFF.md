## What Exists (Working MVP)

### Auth & Multi-tenancy
- **Staff auth:** Clerk Organizations (sign-in/sign-up at `/sign-in`, `/sign-up`)

- **Parent auth:** Custom JWT (`skuli_token` cookie, `/api/auth/parent`, `/api/parent/login`)
- **Data isolation:** `schoolId`-based scoping via `getUserSchoolId()` helper
- **Role system:** 20+ roles with hierarchy + module access (`src/lib/roles.ts`)

### Design System
- **Dark-first:** `#0A0A0A` background, `#111111` surface, `#7DD3FC` accent
- **Tokens:** Defined in `globals.css` via `@theme inline` (Tailwind v4)
- **Components restyled:** Homepage, login pages (all 6), dashboard sidebar, student layout, parent portal layout, Mwalimu chat
- **3D effects:** Parallax tilt on homepage hero + report card (removed), scroll reveals via IntersectionObserver
- **Font:** Geist/Inter, tight tracking, editorial feel

### Database (Neon Postgres + Prisma)
- **29 tables** including: schools, staff, students, classes, attendance, exams, cbc_results, assignments, library_books, materials, mwalimu_messages, announcements, timetables, notifications, etc.
- **Schema synced** via `prisma db push` (no migration history — use `prisma db push` not `migrate`)
- **New models:** `Material` (file uploads), `MwalimuMessage` (AI chat logs)
- **New fields on School:** `plan`, `isPilot`, `pilotStartDate`, `pilotEndDate`, `chatEnabled`

### Infrastructure

## What's NOT Done / Known Issues

### Light-themed pages (not yet restyled to dark)
These pages still use the old white/slate theme:
- `/dashboard/students` — students table
- `/dashboard/staff` — staff management
- `/dashboard/classes` — class management
- `/dashboard/attendance` — attendance tracking
- `/dashboard/exams` — exams & grading
- `/dashboard/timetable` — timetable management
- `/dashboard/assignments` — assignments
- `/dashboard/notifications` — notifications
- `/dashboard/settings` — settings
- `/dashboard/analytics` — analytics
- `/student` — student dashboard home
- `/student/assignments`, `/student/timetable`, `/student/announcements`
- `/portal` — parent dashboard home
- `/portal/attendance`, `/portal/assignments`, `/portal/messages`
- All API response pages

### Missing features
- **`chatEnabled` flag** — exists in schema but not wired to class chat route gate
- **Report cards** — removed for MVP. The `cbc_results` and `student_competencies` tables exist, the API `/api/cbc` works, but there's no UI to view/generate report cards
- **Fees module** — `MODULE_ACCESS.fees` is empty array, no fee tracking UI
- **File uploads** — Vercel Blob is set up for Materials only, not for school logos, student photos, etc.
- **Email notifications** — Resend is configured but not actively sending
- **Real-time** — Class chat uses polling, not WebSockets
- **Mobile responsive** — Most dashboard pages work but aren't optimized for small screens
- **Print/PDF** — Report card print was removed with the component

### Technical debt
- `prisma db push` used instead of proper migrations — no migration history
- Some pages still import from `@/generated/prisma/client` directly instead of `@/lib/prisma`
- Middleware uses deprecated `middleware` convention (Next.js wants `proxy` instead)
- `study_materials` table still exists alongside new `materials` table (legacy)

```bash

npx prisma generate

# Dev
npm run dev

# Push schema changes to DB
```
